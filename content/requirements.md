## Software Requirements

Java Modelling Tools is platform-independent and requires only the
[Java Runtime Environment](http://www.java.com/en/download/manual.jsp)
(version 1.8 or later).

*All* required libraries are included within the download packages.

## Testing Platforms

Java Modelling Tools has been successfully tested with:

- Microsoft Windows
- macOS
- Linux Ubuntu
