## Current Stable JMT Version: 1.5.0

Java Modelling Tools download packages:

1. **FULL Version** (includes JMT, installer, manuals, examples, shortcuts)
   with graphical installer. *(Recommended)*

   [Download it here](https://sourceforge.net/projects/jmt/files/jmt/JMT-1.5.0/JMT-installer-1.5.0.jar/download)

2. **JAR Version** (includes JMT), no installer. *(For users with installation
   problems)*

   Run JMT from the command line as follows:
   `java -jar JMT-singlejar-1.5.0.jar`

   [Download it here](https://sourceforge.net/projects/jmt/files/jmt/JMT-1.5.0/JMT-singlejar-1.5.0.jar/download)

3. **SOURCES** are available on the
   [git repository](https://github.com/Java-Modelling-Tools/jmt) of the project.

   The code is compiled and packaged using [Apache Maven 3](http://maven.apache.org/).
