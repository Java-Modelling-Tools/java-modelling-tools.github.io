## Project Description

Java Modelling Tools (JMT) is a suite of applications released under GPL
license. The project aims at offering a comprehensive framework for
performance evaluation, system modeling with analytical and simulation
techniques, capacity planning and workload characterization studies.

The current stable version of the suite includes six Java applications:
[JSIMgraph](/tools/jsimgraph/), [JSIMwiz](/tools/jsimwiz/),
[JMVA](/tools/jmva/), [JABA](/tools/jaba/), [JWAT](/tools/jwat/) and
[JMCH](/tools/jmch/).

## Getting Started

**New users**: new to JMT? Check out the
[manual](/papers/JMT_users_Manual.pdf), the
[book](https://link.springer.com/book/10.1007/978-3-031-36763-2), the
[video lectures](https://www.youtube.com/watch?v=kR_-by3u8JM&list=PL5yYxD_4CokRTQt-cI2y5m3m-p3FhUsSe),
and the [video demos](https://www.youtube.com/watch?v=HTtQQVrXpx0&list=PL5yYxD_4CokS18VQIAAWhzOySQYnPlV2b).

**Release announcements**: please subscribe to the
[jmt-announce](https://lists.sourceforge.net/lists/listinfo/jmt-announce) list.

**API**: do you need to control JMT simulations programmatically? Check out
[LINE](http://line-solver.sf.net/) (available for Java, MATLAB and Python).
